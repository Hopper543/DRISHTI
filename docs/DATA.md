# Data: sources, provenance, redistribution and loading

## Evidence classes

| Class | Meaning | In this repo |
|---|---|---|
| `REAL_MEASURED` | values reported by a source for a physical device | NASA TID report rows, SECOM |
| `REAL_DERIVED` | real quantities transformed by the source (e.g. % ESR increase) | capacitor #14 (local only) |
| `SYNTHETIC` | generated by the project's seeded generator | burn-in demo fixture and everything trained on it |

Every table, upload and result carries exactly one class; an upload with mixed classes is refused, and classes
are never concatenated into one training matrix or one metric.

## Loading

A clone already contains everything the demo, tests and dashboard need. To add the local-only real tables from
the dataset package (checksums are verified against the package's `docs/file_checksums.json` first):

```bash
.venv\Scripts\python scripts/prepare_data.py --package-dir "<path>\drishti_dataset_v1"
```

This writes `data/local/` (git-ignored). The loaders prefer the full local table when present and otherwise use
the public subset; the dashboard states which scope is loaded.

Larger optional archives (NASA MOSFET #13 ≈ 7.85 GB, capacitor #12 ≈ 5.04 GB) were inspected by the dataset
package but not opened or included; its `scripts/download_optional.py` handles them with disk-space checks.

## Data rules enforced in code

| Rule | Where |
|---|---|
| Unknown labels are unknown, not healthy | real rows have no latent-defect labels; real route gives no PASS/FAIL |
| Respect source quality flags | `quality_flags` → no automated peer verdict (`A_UNTRUSTED_SOURCE_FLAG`, `UNTRUSTED_NO_VERDICT`) |
| AD620 unresolved bias → no trusted verdict | `drishti/real.py` (`peer_group == UNRESOLVED`) |
| Channels / repeated measurements of one package stay together | device folds from the package; real peers compared within the same channel |
| Whole-lot synthetic partitions | test `test_whole_lot_split_isolation` |
| SECOM dates are not lots | `group_kind = calendar_date_NOT_lot` (tested) |
| No dose → burn-in hours | real route refuses rows with radiation dose and burn-in hours (tested) |
| IGBT excluded from physical-limit decisions and normal training | never loaded by any pipeline; not committed |
| No concatenation of unrelated datasets | separate loaders and evaluation functions per dataset |

## Synthetic fixture details

See `data/demo/generator_assumptions.json` and the dataset package's `scripts/generate_synthetic.py`. Splits:
90 train, 15 validation, 45 calibration, 30 ordinary test, 12 shifted test, 12 edge lots; no device or lot
crosses a split. The demo batch (`data/fixtures/demo_batch_SYNTHETIC.csv`) contains five whole held-out lots
unchanged plus **one illustrative lot** `ILLUSTRATIVE_Q155` — lot SYN_L155 with threshold voltage rounded to
0.1 V to demonstrate zero-MAD handling. It is labelled as illustrative in its IDs, the dashboard and the docs.
